# Portfolio Tactical Overlay Analysis

This self-contained public release examines whether rebalancing, cash reserves, drawdown responses, volatility controls, or trend-based leverage improve a strategic multi-asset portfolio without creating a fragile or impractical trading rule.

Open `Portfolio_Tactical_Overlay_Analysis.ipynb` from this directory. The saved notebook already contains all outputs. To reproduce them, run all cells with the working directory set to this folder; every input is read through a relative path under `data/`.

The notebook requires Python with NumPy, pandas, Matplotlib, IPython, and Jupyter support. No network access is required for execution.

The release contains only the notebook, its three input data files, this guide, and `DATA_NOTES.md`.
